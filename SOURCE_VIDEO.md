# AERIS native video validation

This public repository validates only the dependency and native-build surface required by the private AERIS mobile video-call implementation.

Validated versions:

- Expo SDK 57.0.10
- React Native 0.86.2
- @livekit/react-native 2.11.1
- livekit-client 2.21.0
- @livekit/react-native-webrtc 144.1.1
- TypeScript 6.0.3

The harness contains no backend source, credentials, user data, messages, provider keys or production configuration.
